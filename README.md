QODER Регер — последовательная регистрация аккаунтов

Возможности:
- Загрузка списка из CSV или TXT (форматы: `email`, либо `email:password`).
- Окно с текущим аккаунтом, заметками и статусом.
- Кнопки: копировать email/пароль, открыть URL регистрации, отметить успех/фейл/пропуск, переход по списку.
- Сохранение прогресса в CSV.

Запуск:

1) Установите зависимости:

```bash
cd /workspace
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

2) Запустите приложение:

```bash
python -m app.main
```

Подсказки:
- В поле "Рег. URL" можно задать шаблон, например: `https://example.com/register?email={email}` — подставится текущий email.
- Список в TXT должен быть по одному аккаунту на строку; поддерживается `email:password`.
- Для 1000+ аккаунтов используйте сохранение прогресса периодически.

# Roadmap: WB Seller Analytics — Платформа для продавцов одежды

## Миссия

Превратить текущую аналитическую платформу в **специализированный инструмент для продавцов одежды на Wildberries** — с глубокой проработкой ключевых слов, отслеживанием позиций и нишевыми метриками, которые критичны именно для fashion-сегмента.

---

## Текущее состояние (v0.2 — Persistence)

| Компонент | Статус | Описание |
|-----------|--------|----------|
| Gateway | Готов | API-шлюз, маршрутизация, CORS |
| Auth | Готов + DB | JWT, регистрация, API-ключи → PostgreSQL |
| Collector | Готов + DB | Сбор продаж/заказов/остатков → PostgreSQL |
| Stock Analytics | Готов | Анализ остатков, рекомендации по поставкам |
| Sales Analytics | Готов | Дашборд продаж, ABC-анализ, тренды |
| Competitor | Готов | Поиск конкурентов, анализ цен |
| SEO | Готов + DB + Redis | Позиции → PostgreSQL, кэш поиска → Redis |
| Notifications | Готов + DB | Алерты, каналы, правила → PostgreSQL |
| PostgreSQL | Готов | Персистентность всех данных |
| Redis | Готов | Кэш поиска WB (TTL 15 мин) |
| Fashion Keywords | Готов | Словарь, генератор, кластеризация |
| Positions Pro | Готов | Регионы, конкуренты, прогнозы |
| Fashion Analytics | Готов | Размеры, сезоны, тренды, возвраты |
| Card Optimization | Готов | SEO-аудит, генератор контента, снэпшоты |
| Smart Alerts | Готов | Умные алерты, Telegram/webhook/email |
| Web Dashboard | Готов | Next.js + TypeScript + Tailwind CSS |

**Ограничения текущей версии:**
- Ключевые слова генерируются из fashion-словаря (нет внешнего API частотности)
- Нет CRON-планировщика для автоматической проверки позиций
- Нет очереди задач (NATS/RabbitMQ) для асинхронных операций

## Фаза 2: Продвинутый блок ключевых слов (3 недели)

### 2.1 Расширенный сбор ключевых слов
- [ ] Парсинг подсказок WB (`/api/v1/search/suggestions`) — автокомплит
- [ ] Сбор ключевиков из карточек конкурентов (название, описание, характеристики)
- [ ] Интеграция с Keyword Data API (частотность запросов)
- [ ] Генерация LSI-ключевиков (семантически связанные слова)

### 2.2 Кластеризация ключевых слов
- [ ] Группировка ключевиков по семантическому ядру
- [ ] Автоматическое определение кластеров:
  - **Базовые** (платье, юбка, куртка)
  - **С атрибутами** (платье летнее, юбка плиссе, куртка зимняя)
  - **Длиннохвостые** (платье летнее в цветочек макси)
  - **Брендовые** (платье zara стиль)
- [ ] Визуализация кластерной карты ключевиков
- [ ] Расчёт потенциала кластера (суммарная частотность)

### 2.3 Ключевые слова для одежды — специализация
- [ ] Словарь fashion-терминов:
  - Типы одежды: платья, юбки, брюки, куртки, пальто, блузки, топы, джинсы...
  - Материалы: хлопок, лён, шёлк, полиэстер, вискоза, шерсть, кашемир...
  - Стили: casual, офисный, спорт, streetwear, бохо, минимализм, оверсайз...
  - Сезоны: весна-лето, осень-зима, демисезон, межсезонье
  - Размеры: S, M, L, XL, XXL, plus-size, oversize
  - Цвета: базовые + трендовые (терракотовый, лавандовый, мятный...)
  - Поводы: офис, свидание, прогулка, вечеринка, свадьба, пляж
- [ ] Автогенерация комбинаций ключевиков из словаря
- [ ] Подсказка релевантных fashion-ключевиков на основе карточки товара
- [ ] Анализ «упущенных» ключевиков — слова, по которым ранжируются конкуренты, но не ваш товар

### 2.4 Частотность и конкурентность
- [ ] Оценка частотности каждого ключевика (высокая/средняя/низкая)
- [ ] Оценка конкурентности (сколько товаров по запросу)
- [ ] Расчёт KEI (Keyword Effectiveness Index) = частотность / конкурентность
- [ ] Рекомендации: по каким ключевикам стоит продвигаться

## Фаза 3: Отслеживание позиций — Pro (2 недели)

### 3.1 Расширенный трекинг
- [ ] Проверка до 20 страниц (вместо 5)
- [ ] Трекинг позиций по нескольким регионам (Москва, СПб, регионы)
- [ ] Трекинг позиций отдельно для мобильного и десктопного поиска
- [ ] Исторические графики позиций (день/неделя/месяц)

### 3.2 Конкурентные позиции
- [ ] Одновременное отслеживание позиций конкурентов по тем же ключевикам
- [ ] Сравнительная таблица: ваш товар vs топ-5 конкурентов по каждому ключевику
- [ ] Алерты: конкурент обогнал вас по ключевому запросу

### 3.3 Прогнозирование позиций
- [ ] Тренд-анализ: растёт / падает / стабильно (с учётом скорости изменения)
- [ ] Прогноз позиции на следующую неделю (линейная экстраполяция)
- [ ] Корреляция: как позиции влияют на продажи
- [ ] Автоматические рекомендации по удержанию/росту позиций

### 3.4 Влияние SEO-действий
- [ ] Трекинг событий: когда менялся заголовок/описание/ключевики в карточке
- [ ] Связывание изменений в карточке с изменениями позиций
- [ ] A/B аналитика: до и после смены ключевиков

## Фаза 4: Fashion-аналитика — нишевые метрики (3 недели)

### 4.1 Размерная аналитика
- [ ] Анализ продаж по размерам (какие размеры покупают чаще)
- [ ] Рекомендации по размерной сетке: какие размеры докупить
- [ ] Прогноз: какие размеры закончатся первыми
- [ ] Конверсия по размерам (заказ → выкуп)

### 4.2 Сезонная аналитика
- [ ] Автоматическое определение сезонности товара
- [ ] Календарь сезонов одежды:
  - Февраль-март: весенние коллекции
  - Май-июнь: летние коллекции
  - Август-сентябрь: осенние коллекции
  - Октябрь-ноябрь: зимние коллекции
- [ ] Рекомендации: когда начинать продвижение сезонного товара
- [ ] Прогноз спроса с учётом сезонности
- [ ] Алерты: «через 2 недели начинается сезон — подготовьте остатки»

### 4.3 Трендовая аналитика
- [ ] Мониторинг трендовых ключевиков в категории одежды
- [ ] Отслеживание роста спроса на конкретные стили/цвета/материалы
- [ ] Рекомендации: какие товары создать/закупить под тренд
- [ ] Интеграция с трендами Google/Яндекс (опционально)

### 4.4 Аналитика возвратов (для одежды критично)
- [ ] Процент возвратов по каждому товару
- [ ] Причины возвратов (не подошёл размер, не соответствует фото, качество)
- [ ] Корреляция: описание товара → процент возвратов
- [ ] Рекомендации по снижению возвратов (точные замеры, фото на модели)

## Фаза 5: Оптимизация карточки товара (2 недели)

### 5.1 SEO-аудит карточки
- [ ] Проверка заполненности всех полей карточки
- [ ] Анализ заголовка: есть ли ключевые слова, длина, читаемость
- [ ] Анализ описания: плотность ключевиков, уникальность
- [ ] Анализ характеристик: заполнены ли все обязательные поля для одежды
- [ ] SEO-скоринг карточки (0-100 баллов)

### 5.2 Генератор контента для одежды
- [ ] Генерация SEO-заголовков из ключевых слов
- [ ] Генерация описаний с учётом fashion-терминологии
- [ ] Шаблоны для разных типов одежды
- [ ] Рекомендации по фото (количество, ракурсы, модель/манекен/flatlay)

### 5.3 Мониторинг изменений
- [ ] Снэпшоты карточки (название, описание, цена, фото)
- [ ] Уведомления при изменениях конкурентами своих карточек
- [ ] История изменений с привязкой к позициям и продажам

### 6.1 Конкурентная разведка

- [ ] Рекомендации по скидкам и участию в акциях WB
